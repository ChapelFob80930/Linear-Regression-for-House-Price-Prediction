# House Price Prediction using Linear Regression

This repository contains a project for predicting house prices using Linear Regression. The implementation and analysis are done using Jupyter Notebooks.

## Overview

House price prediction is a fundamental problem in real estate data analysis. By leveraging linear regression, this project aims to build a predictive model based on various features of houses, such as size, location, and other attributes.

## Features

- **Data Preprocessing**: Clean and preprocess the dataset to handle missing values and outliers.
- **Exploratory Data Analysis (EDA)**: Visualize and analyze relationships between features and house prices.
- **Linear Regression Model**: Train and evaluate a linear regression model for predicting house prices.
- **Error Analysis**: Assess the performance of the model using metrics like Mean Absolute Error (MAE) and Root Mean Squared Error (RMSE).

## Installation

To run the project, ensure you have the following installed:

- Python (>= 3.8)
- Jupyter Notebook
- Required Python libraries (specified in `requirements.txt`)

### Install Dependencies

You can install the required dependencies using pip:

```bash
pip install -r requirements.txt
```

## Usage

1. Clone the repository:
```bash
git clone https://github.com/ChapelFob80930/Linear-Regression-for-House-Price-Prediction.git
```

2. Navigate to the project directory:
```bash
cd Linear-Regression-for-House-Price-Prediction
```

3. Open Jupyter Notebook:
```bash
jupyter notebook
```

4. Run the notebooks in sequence to execute the data analysis and model training.
